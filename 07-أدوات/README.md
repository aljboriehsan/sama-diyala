# أدوات إعادة توليد الشعار

- final_paths.json: مسارات الشعار النهائية (الطائرة، القوس، الأشرطة، الحروف، الاسم، الشعار النصي).
- mk3.py: يبني كل نسخ الشعار (العمودي، الأفقي، الرمز، الأحادي) بصيغتي SVG وPNG.

التشغيل:

    pip install cairosvg --break-system-packages
    python3 mk3.py

الألوان معرّفة في أعلى mk3.py: الأخضر #0E4D2C، الذهبي #C9A44C، ذهبي النص #A8862F.
